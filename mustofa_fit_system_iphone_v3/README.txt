MUSTOFA FIT SYSTEM — iPHONE PWA

The iPhone Files/ChatGPT preview may show HTML as a single static page instead of running the app.
For full interaction, host these files on an HTTPS web address.

GitHub Pages:
1. Create a new GitHub repository.
2. Upload index.html, manifest.json, and sw.js.
3. Settings > Pages > Deploy from branch > main > /root.
4. Open the generated HTTPS URL in Safari.
5. Safari Share > Add to Home Screen.

After installation, Mustofa Fit opens like an app.
